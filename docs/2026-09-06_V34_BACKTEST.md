## Empfehlung (Claude, 06.09.2026)

**Der Kandidat funktioniert.** Alle Varianten verbessern v3.3 in **allen** Segmenten und
Liquiditaetsklassen. Der Effekt ist damit robust, nicht das Ergebnis einer gluecklichen
Parameterwahl. Er greift ausschliesslich bei liquider Basis; fuer Karten mit 1-2 Verkaeufen
bleibt das Verhalten identisch zu v3.3 (Median 42,4 % unveraendert).

**Der Zielkonflikt:** Je kuerzer die Halbwertszeit, desto genauer der Median **und** desto
unruhiger der Wert.

| Variante | Median gesamt | Bias | Sprunghoehe | Bewertung |
|---|---|---|---|---|
| v3.3 (live) | ±23,9 % | +1,7 % | 4,1 % | ruhig, aber ungenau |
| C: /(1+n/10) | ±23,5 % | +1,7 % | 5,0 % | zu wenig Gewinn fuer die Unruhe |
| **D: /(1+n/5)** | **±23,2 %** | **+1,9 %** | **5,5 %** | **empfohlen** |
| F: /(1+n/4) | ±23,1 % | +1,9 % | 5,7 % | wie D, minimal aggressiver |
| G: /(1+n/3) | ±23,0 % | +1,9 % | 6,0 % | vertretbar, wenn Genauigkeit Vorrang hat |
| H: /(1+n/2) | ±22,8 % | +1,8 % | 6,5 % | 0,2 Punkte Gewinn fuer 0,5 Punkte Unruhe: schlechter Tausch |
| *avg5 (Wettbewerb)* | ±23,7 % | −3,8 % | 6,1 % | |

**Warum D:** deutlicher Gewinn (0,7 Punkte), Bias bleibt weit unter der 5-%-Grenze,
Sprunghoehe bleibt **unter** der des Wettbewerbs (5,5 % vs 6,1 %), und der Eingriff ist
moderat genug, dass Ueberanpassung an den 25.08.-Datensatz unwahrscheinlich ist.

**Was D erreicht und was nicht:**

| Segment | v3.3 | D | avg5 | Ziel erreicht? |
|---|---|---|---|---|
| GESAMT | ±23,9 % | **±23,2 %** | ±23,7 % | ✅ erstmals besser als avg5 |
| rare/in_season | ±24,1 % | **±22,3 %** | ±25,1 % | ✅ deutlich |
| limited/classic | ±22,4 % | **±21,5 %** | ±23,1 % | ✅ |
| limited/in_season | ±24,5 % | ±24,4 % | **±23,5 %** | ❌ avg5 bleibt vorn |

**Das Langfristziel ist damit NICHT erfuellt.** Es lautet "in ALLEN Segmenten besser als
avg5". Bei limited/in_season, dem volumenstaerksten Segment, liegt avg5 weiter knapp vorn,
und keine der sieben Varianten dreht das. Das ist ein eigenes Problem: dort hilft kuerzere
Gewichtung kaum (24,5 -> 24,4). Naechster Ansatzpunkt waere dort die Verkaufsart
(`deal_type`, seit 05.09. in Erfassung): 79 % der Verkaeufe in diesem Segment sind Sorares
eigene Primaermarkt-Preise, kein Zweitmarkt.

**Risiken / Einschraenkungen:**
- Datensatz vom 25.08., 800 Spieler. Der Effekt ist konsistent, die exakte Staerke nicht.
- Sieben getestete Varianten erhoehen das Ueberanpassungsrisiko. D ist bewusst nicht das
  Optimum der Stichprobe (das waere H), sondern die konservativere Wahl.
- Nach einem Deploy gilt die Aenderungssperre fuer `market_move` wie bei v3.3 (Cut setzen,
  sonst vergleicht die Marktbewegung zwei Formel-Generationen).

**Kein Deploy ohne Freigabe.** Wenn Jonas zustimmt: `lib/fmv.mjs` anpassen (zweistufig
zaehlen/gewichten wie im Backtest), Smoke-Test der Randfaelle, Push, Change-Guard-Migration
